위 도구줄 아이콘 시안 — 크기를 가지런히, 도움말은 맨 뒤로

버튼 상자는 이미 26×26 로 같습니다. 어긋나는 것은 그 안의 글리프입니다 — 유니코드 기호는 글꼴이 정한 크기대로 그려져서, 같은 15px 로 찍어도 ⚙ 는 꽉 차고 ⌕ 는 눈에 절반으로 보입니다. 점선은 아이콘이 차지해야 할 20×20 자리입니다.

지금 문제

유니코드 글리프 6개. 상자는 같고 안이 제각각입니다. ⌕(찾기)가 가장 작고, ? 는 획이 얇아 다른 것과 무게가 안 맞습니다. 순서도 도움말이 두 번째에 끼어 있습니다.

안 A — 이미 만들어 둔 PNG 아이콘 세트 추천

이미 있는 것을 쓰는 안입니다. assets/icons/ 에 settings·undo·search·pin·help 가 16·20·24·32·48px 로 구워져 있습니다 (2026-07-29 제작, make_block_icons.py). 획 굵기를 상자 크기의 비율로 잡고 회색 한 색으로 통일해 만든 세트라, 넣는 순간 가지런해집니다. 없는 것은 도킹 하나뿐이라 같은 화풍으로 하나만 더 그리면 됩니다. 순서는 설정 · 되돌리기 · 찾기 · 항상위 · 도킹 ｜ 도움말 — 도움말만 구분선 뒤로 뺐습니다(자주 안 쓰는 것은 끝에).

안 B — 유니코드 유지 + 글리프별 크기 보정 가벼움

글꼴이 그리는 크기를 글리프마다 다르게 지정해 눈높이를 맞추는 안입니다 (⌕ 13 → 🔍, ↺ 16, ◫ 16 …). 파일을 안 늘리고 한 줄로 끝나지만, 글꼴에 따라 다시 어긋납니다 — 선생님 PC 와 배포 받은 PC 의 글꼴이 다르면 보정값이 헛돕니다. 임시로 쓸 만하고 최종안으로는 약합니다.

안 C — A 와 같지만 아이콘을 22px 로 대안

A 는 20px, 이것은 22px 입니다. 26×26 상자에서 22px 는 여백이 2px 뿐이라 또렷하지만 빽빽합니다. 4K 에서 작다고 느끼시면 이쪽입니다.

정하실 것

① A / B / C 중 하나   ② 도킹 아이콘 가 / 나 / 다 중 하나   ③ 순서를 설정·되돌리기·찾기·항상위·도킹 ｜ 도움말 로 두는 것이 맞는지.
